# ArPI webapplication 🛡️

[![Demo page build](https://github.com/ArPIHomeSecurity/arpi_webapplication/actions/workflows/deploy-demo.yml/badge.svg)](https://github.com/ArPIHomeSecurity/arpi_webapplication/actions/workflows/deploy-demo.yml)

The webapplication to control the system (argus_server).

* 🌐 Project page: https://www.arpi-security.info/
* 📘 Project documentation: https://docs.arpi-security.info/
* 🚀 Remote application: https://app.arpi-security.info/
* 📱 Google Play: https://play.google.com/store/apps/details?id=com.arpi.webapplication
* 🧪 Demo: https://demo.arpi-security.info/

## Overview 🧭

This project is built with Angular, Ionic, and Capacitor. It supports multiple deployment targets, localized builds, and a mobile packaging flow for Android.


## Prerequisites 🧰

Install a current Node.js and npm environment, then install dependencies with npm install.
